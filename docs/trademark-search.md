# Ladilala: preliminary trademark and name search

Date: 2026-11-17. Not legal advice. This is a quick public search by an AI agent, not a clearance opinion.

## Scope

- Name: Ladilala (also LaDiLaLa, La Di La La; Vietnamese: "Lặp Đi Lặp Lại").
- Product: Windows desktop software that manages browser profiles and automates web forms.
- Nice classes checked: 9 (software), 42 (SaaS), 35 (business services). 38 and 41 only if media use.
- The user decided: updates stay on `ladilala.71.zone`. No domain is bought now.

## Method

1. WIPO Global Brand Database, brand-name search, "contains the word" mode (https://branddb.wipo.int, read 2026-11-17). Terms: ladilala, ladila, ladilla, radilala, ladilalah, ladi lala, la di la la, ladi-la-la, lalala.
2. USPTO trademark search (https://tmsearch.uspto.gov, read 2026-11-17), term ladilala.
3. Web search for the name with software, app, extension, GitHub, npm, store words.
4. Domain check by Google public DNS over HTTPS (https://dns.google/resolve). Handle check by HTTP status of public pages. Local `dig` timed out and gave no result.

## Risk rating

Overall: **low to medium** for use as a product name. **Medium** if the user files a trademark in Vietnam.

- Low: no exact or near-exact mark in classes 9, 42 in WIPO or USPTO. No software product with this name.
- Medium: LADILA is registered in Vietnam in class 35. The owner is a herbal medicine firm, a different business, but NOIP may cite it against a class 35 filing. Class 9 and 42 filings are safer.
- Low: the Nekes track and any LaDiLaLa music act are in music. A song title does not block software.
- Weak name: a repeated syllable phrase is easy to confuse with lalala, Lala, LADILA. Search engines will show music first.
