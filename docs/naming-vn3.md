# Names round 4: Vietnamese consumer-brand style (worker namevn3, 2026-11-16)

Plain unranked lists. No ranking, no pick. Not legal advice. Builds on docs/naming.md, naming-vn.md, naming-vn2.md.

## 1. Rules
- User: "Vietnamese-friendly English names is sth like Momo, ShipFast, BookNhanh... For VN syllables, I dont remember to restrict the name into 2 syllables only? Also I accept some meaningful name like GiaoHangNhanh, GiaoHangTietKiem"
- Earlier limits dropped (2 to 3 syllables, 4 to 8 letters, no Vietnamese words). Long names allowed.
- Four styles: A short brands, B English two-word, C English + Vietnamese hybrid, D Vietnamese phrases and syllable-prefix blends.
- Neutral register: no hide, stealth, ghost, mask, bot, scraper words.
- Table cells T = taken (RDAP 200 or DNS NS exists), F = free-likely (RDAP 404 and no NS), ? = unknown. Nothing bought.
- Domains: .com (Verisign RDAP), .app and .dev (Google RDAP), .io (Identity Digital RDAP), .vn and .com.vn by DNS NS only (weaker signal, no usable RDAP). GH = GitHub user or org (gh api). npm = registry.
- Conflict = top two web search hits for "<name> phần mềm OR app OR company". It is a first signal, not a trademark search. Hits are not always the same business.
- Gemini and ChatGPT names were checked by me with the same script.
