# Names round 3: Vietnamese-friendly English names and syllable-prefix blends (worker namevn2, 2026-11-16)

Plain lists to choose from. No ranking, no pick. Not legal advice. Builds on docs/naming.md and docs/naming-vn.md.

## 1. Rules
- User rule: "Vietnamese friendly english name, not vietnamese words. If u wanna use vietnamese word: Vietnamese syllable-prefix blending: first 2-3 letters of each Vietnamese syllable (remove diacritics), original order, short pronounceable name, meaningful Vietnamese origin."
- Examples: Long Thanh -> Lo + Tha = Lotha; Binh An -> Bi + An = Bian; Minh Tam -> Mi + Ta = Mita; Hoa Hop -> Hoa + Hop = Hoahop; Long Thanh + Milk = Lothamilk. Output: phrase -> brand name.
- Neutral: no stealth, ghost, shadow, mask, bot, scraper register; not tied to Windows.
- List A: 2 to 3 syllables, 4 to 8 letters, spelled as said, no hard clusters, no -r -l -s -z -v -k -x endings, checked in Vietnamese split with and without tones. Each of the 30 passes the length rules; 3-syllable coins marked.
- List B: every blend uses 2 or 3 letters per syllable (shown in the derivation), phrase is meaningful for the product. Gemini and ChatGPT derivations were re-checked by me against this rule.
- Cells: T = taken (RDAP 200 or DNS NS found), F = free-likely (RDAP 404 and no DNS), ? = unknown. .com/.app/.io/.dev via RDAP plus dns.google NS; GitHub user or org via gh api; npm registry. Nothing was bought. Almost every short name has a taken .com.
- Conflict column: first strong web search hits; "none exact" means only fuzzy lookalikes came back. Items tagged ChatGPT or Gemini were not verified by me.

## 4. Dropped names and why
- Bad Vietnamese reading: Cunha ("cu nha", flagged by both bots), Donhan (no tones = "đớn hèn", Gemini; ChatGPT: "đơn hàng"), Vuva ("vú"), Kumo ("cu"), Bevu ("bê vú" risk), Cado ("cá độ"), Dogia ("đồ giả"), Dobo ("đồ bộ"), Dienha, Dieso ("die").
- Does not follow the rule or arbitrary: Giemam, Thuanbuom, Xepgon, Nhagon, Hosohub (descriptive suffix, weak).
- Taken or strong brand: Tigo (telecom), Anta, Doha (city), Mocha (Viettel app), Thaco, Tica, Ludo, Qualy, Ondi, Chubi, Dobo (app), Mimo, Luma, Mavi, Noma, Tempo, Mobi (ebook format), Sora, Kova, Velo, Zeno, Tera, Vina.
- Hard to say or cluster: Orcha, Harmo, Nesto, Portu, Ritmo, Ghinho, Canban (Kanban), Moron, Mala (Spanish: bad).
- Valid but cut for pool size (own raw): Ramo, Hamo, Dovi, Rivo, Meno, Havo, Tenno, Wovo, Seamo, Loomo, Pacey, Marlo, Nuvia, Tolio, Yarno, Dalio, Baymo, Monoi variants, Goga variants.
